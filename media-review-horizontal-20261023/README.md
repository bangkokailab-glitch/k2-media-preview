# K2 media horizontal-card comparison

This separate test route retains the existing review site. On desktop, the two smaller cards place their image on the left and article information on the right. All desktop story images use a shared 5:3 aspect ratio. Mobile uses the existing layout.

Eighteen display slots, alternating large-card position, existing article copy, header, logo, guide banner, typography and list links are preserved. Articles and dates remain placeholders; date-based WordPress retrieval is not implemented.

No production publishing or client emails are part of this comparison.
