# K2 Family Office 記事詳細の基本型

2026-10-26 改訂。対象は `layout: editorial`、`template: editorial-v2` の記事。
著者紹介はCタイプ（小さな写真の中央配置カード）を採用。旧 `author=card-a` 等のURLでもCを表示する。比較ページからの `compare=author` 指定時のみ別案を表示できる。

## 固定する順番

| 順番 | 部品 |
|---|---|
| 1 | H1・メイン画像 |
| 2 | 導入文 |
| 3 | 冒頭の会話（読者の疑問・K2の回答） |
| 4 | NOTE（冒頭の補足のみ） |
| 5 | 既存の横長「ファミリーオフィスを知る」バナー |
| 6 | H2/H3から自動生成する目次 |
| 7 | H2・本文・H3・本文。必要な箇所に注意喚起等 |
| 8 | まとめH2 |
| 9 | KEY POINT |
| 10 | まとめの会話 |
| 11 | まとめ文 |
| 12 | 区切り線 |
| 13 | 著者情報Cタイプ |
| 14 | 既存の横長ガイドバナー |
| 15 | あわせて読みたい記事 |

まとめ内のNOTEと、本文末のテキストCTAは削除。再生成しても復活させない。

## 編集箇所

- 本文は `assets/articles.js`。`introParagraphs`、`openingBlocks`、`sections`、`summary`、`points`で編集する。
- `summary.blocks`は会話(`qa`)→本文(`paragraph`)。KEY POINTはrendererがまとめH2の直下に配置する。
- `blocks.type`は `paragraph` / `heading`(H3) / `qa` / `risk-list` / `note`。
- H3のIDは重複させない。目次・検索対象はデータから生成する。
- バナーHTMLは `assets/app.js` の `articleGuideBanner(place)`。横長は導入後と著者直下、正方形はPCサイドバーのカテゴリー上部。
- ガイドURLは未確定。現在は `data-pending="guide"` の準備中ダイアログ。確定後に実際のhrefを設定しdata-pendingを外す。

## 表示上のルール

- 本文最大620px、本文15px以上、英語ラベルは既存の小さいサイズ。
- 著者写真48px。仮配置の注記は表示しない。
- スマホでも回答ロゴは吹き出しの右隣の同じ行に置く。ロゴだけを上段へ移さない。
- 正方形ガイドバナーは右サイドバーがある1051px以上で表示。小画面では本文の横長バナーを使う。
- 関連記事タイトルは最大2行。短い題名も2行分の高さを確保して揃える。
- 追加したまとめ文は構成確認用の文案。正式原稿の確認は別工程。
